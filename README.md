One letter for the day: B, for burnout. A single character that carries the whole day — one long day of bounties, a rejected entry fixed and resubmitted, a deleted video, a haiku sent at dusk. The program writes exactly that one byte to entry.txt, no trailing newline, so the sealed gate (1 to 1 characters) passes under any reading.

## Run it

```sh
python3 main.py
```
